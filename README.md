## 页面里有什么

一个以文字阅读为主、以图像和导图补充的个人展示网站。通过清晰的栏目组织，让访问者从简短介绍进入经历与项目细节。

| 栏目 | 展示内容 |
| :--- | :--- |
| **个人介绍** | 简短背景、关注方向与页面导航 |
| **项目作品** | 按主题分组的项目列表、成果缩略图与独立详情页 |
| **经历** | 分开展示实践经历与教育背景，使用时间轴组织内容 |
| **技能** | 按类别整理常用工具与技术，配合简洁图标 |
| **个人侧写** | 工作之外的性格、兴趣与个人表达 |

## 项目如何讲述

项目列表提供名称、简介和预览图，点击进入详情页，沿着一条完整的线索阅读：

**业务问题 → 关键思路 → 实现方法 → 结果与验证**

- 用分支导图解释方法与实现链路。
- 用界面截图呈现可见成果。
- 用简洁指标突出结果，同时保留必要的范围说明。
- 在经历中连接相关项目，方便从工作内容继续了解具体实践。

## 设计与交互

🌙 **深色与浅色** — 默认采用柔和的深色背景，可切换浅色主题。

📖 **专注阅读** — 居中内容、清晰标题、克制装饰与适量留白。

🧭 **分层导航** — 顶部栏目导航与项目详情返回入口，减少长页面中的查找。

📱 **响应式布局** — 随屏幕宽度调整文字、缩略图与导图布局。

## 发布方式

当前公开页面由 `site/` 中的静态文件提供，通过 GitHub Actions 自动部署到 GitHub Pages。

```text
site/
├── index.html        页面入口与基础样式
├── content.js        经历及基础内容
├── projects-v2.js    项目详情、导图与展示逻辑
├── editor.js         已保存文字的加载逻辑
├── edits.json        文字覆盖数据
└── assets/           截图与标识资源
```

公开页面仅展示内容，不提供在线编辑入口。
